# 浮读 Windows 0.29.2 测试说明

适用于 Windows 10 22H2 x64、Windows 11 x64。此包自带 .NET 运行时，供本次实机测试使用。

## 第一次打开

1. 先退出旧版，把 ZIP **完整解压到新文件夹**，双击 `FloatingReader.exe`。不要只复制 exe，也不要在压缩包内运行。
2. 按微信读书网页提示登录，点击书籍。正文就绪后自动切到纯文字；第一批文字显示后，剩余文字在后台补读。
3. 默认使用 Windows 系统消息字体；字号 14 pt（换算为 Windows 逻辑像素，随系统缩放）、行距 1.4 倍、文字 #333333、背景 #FBF6ED。已有配色保留。要恢复默认值，在窗体上右键选择「恢复默认阅读样式」。
4. 模式按钮表示点击后的目标：正在看纯文字时显示「原网页」，正在看原网页时显示「纯文字」。

如果缺少网页运行组件，安装 [Microsoft Edge WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。微信读书画布文字需要系统中文 OCR：Windows 设置 → 时间和语言 → 语言 → 中文语言选项 → 光学字符识别。

本版增加按已识别边界推进及空识别同位置重试，避免翻过尚未绘制的正文；仍需 Windows 实机验证。

本版补充：点击阅读窗口先激活浮读、恢复键盘焦点，再处理拖动、缩放及按钮事件；置顶与隐藏时也使用相同处理。

## 工具怎么用

- 顶部：书架、后退、文字／网页切换、章节目录、置顶、隐藏／显示工具栏与背景；最右侧键盘按钮修改快捷键。
- 底部：字号滑块、行间距、文字颜色、本机字体、正文背景色。顶部不再放粘贴、深色模式或透明度滑块。
- 文字色与背景色分别保存。选色面板采用色轮、常用色样、颜色值和左白右黑明暗条；面板可以拖动，没有遮罩。关闭面板和隐藏／恢复背景均不应重置颜色。
- 点击隐藏按钮，工具栏、边框和正文背景一起隐藏，文字保持可见；按 **Ctrl+/** 恢复。再次按 Ctrl+/ 可隐藏。
- 关闭正文文字选择。阅读区域按住左键可拖动；隐藏后整个区域均可拖动，四边与四角可缩放。
- 正文底部 **←／→** 换章。目录可搜索章节并打开。
- 「已置顶」用蓝色强调；再次点击或按 Ctrl+P 取消置顶。Alt+F4 关闭并保存位置。

## 阅读和预加载

后台使用固定 1200×2400 大页面读取，显示窗口很小也不缩小读取范围。当前章首批文字显示后，后台并行补读本章、预读下一章；下一章最多准备八屏或约 18000 字，首批可用时即可使用，无需等全部完成。

下滑第一次到达底部就请求接续。若本章还在补读，会先保留当前文字；若下一章缓存尚未完成，会等待首批就绪后自动接在下面，不需要再次点击箭头。手动点击 → 则直接切换到下一章。接手已预读的网页后，立即准备再下一章，避免重复打开同一页。

已完成的缓存不会因闲置定时清除，预读失败后按间隔重试；网页进程失效时尽量保留已缓存文字。网络、书籍访问权限、系统 OCR 和首次登录仍会影响速度。本版不能保证任何书籍都即时加载。

首次升级会重新读取旧的正文缓存以避免旧换行影响折行；登录、配色和快捷键仍保留。每次启动先显示工具栏与背景，避免启动后无法找到操作位置。

## 默认快捷键

| 功能 | Windows 快捷键 |
| --- | --- |
| 显示／隐藏工具栏与正文背景 | Ctrl+/ |
| 置顶／取消置顶 | Ctrl+P |
| 增大／缩小字号 | Ctrl+加号／减号 |
| 上一章／下一章 | Ctrl+↑／↓ |
| 章节目录 | Ctrl+D |
| 纯文字／原网页 | Ctrl+R |
| 快捷键设置 | Ctrl+, |
| 关闭 | Alt+F4 |

可在右上角键盘按钮修改各功能快捷键。设置面板中的输入框仍保留 Windows 的复制、粘贴等操作。

## 今晚建议这样测试

1. 登录打开同一本长章节书，先读第一批文字，同时观察下方的预读状态。
2. 把窗口缩小，确认文字正常折行、正文仍继续大量补充。
3. 滚到底，确认自动接续；再连续读两三章，检查有无重复、缺段、串章。
4. 挂着一段时间，再到下一章，检查是否直接使用缓存。
5. 分别改文字色、背景色，关闭面板，再隐藏／恢复，确认颜色不变。
6. 隐藏后拖动文字区域，四角缩放；多次切换置顶，确认正文和配色不变。
7. 退出重开，确认阅读位置；再核对微信读书原网页的章节。

若有问题，右键「复制阅读诊断」，反馈 Windows 版本、操作步骤、提示及截图。发送前可删除书籍路径等私人信息；不用发送登录配置或 Cookies。

配置保存在 `%LOCALAPPDATA%\FloatingReader`。不要删除此目录来升级；直接使用新解压文件夹启动。

本版已做交叉编译、可移植逻辑与网页章节测试；Windows 10 原生界面、WebView2、中文 OCR 与实际账号的阅读流畅度仍待实机验证。
