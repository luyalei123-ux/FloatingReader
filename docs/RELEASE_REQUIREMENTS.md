# 发布时保留的产品要求

## 颜色选择（用户于 2026-10-20 确认）

- macOS Intel 与 Apple 芯片版共用同一份实现：`NSColorPanel.shared` 系统标准选色窗口，一次编辑文字或正文背景；选色窗口不随阅读配色改变外观。
- 0.26.9 Intel 版的关闭选色窗口、隐藏／恢复配色行为已获用户初步确认。Apple 芯片版沿用该实现，不另换拾色器。
- Windows 尽量保持同样的选色体验：色轮、明暗条（左白右黑）、色样及颜色值输入；保留已有色轮界面，不回退到最初只有 RGB 三条滑块的窗口。Windows 不能直接使用 macOS 的系统颜色面板，需在 Windows 实现相近交互。
- 发布前验证：分别选择文字色和背景色；关闭面板；重新打开；隐藏／恢复工具栏和背景；重新载入保存设置。所有步骤都须保留已选颜色，两个颜色互不覆盖。

## 构建范围

- 2026-11-02 用户要求按步骤准备开源发布：本轮整理 macOS 0.26.18 与 Windows 0.29.2 preview 的源码和下载附件，不执行未经指定目标的 GitHub 上传或公开发布。
- 0.26.10 系统选色器另加应用自带常用色，避免依赖另一台电脑的个人色样；后续 Intel 构建使用同份源码，Windows 也应提供可直接点击的常用色。

## 后台读取与显示分离

- 后台按固定桌面大页面读取，不使用用户浮窗或显示器当前可见区域的尺寸。
- macOS 当前读取尺寸为 1200×2400，下一章首屏即可使用，后台继续补读最多八屏或约 18000 字；显示窗口缩放只影响文字折行。
- 预读不得改变显示窗口的大小、位置、当前文字滚动位置；消费缓存后取消旧预读，不能用迟到结果覆盖新章节。
- 后续 Apple 芯片和 Windows 版本保持同样原则，Windows 具体常量与批量策略需在对应版本中确认。

## 循环预读与闲置

- 下一章缓存就绪时接手已加载的后台页面，立即准备再下一章，避免重复加载当前网页。
- 到达底部即请求继续；缓存暂未完成时保留请求，完成后自动接续。
- 已完成缓存不因闲置定时清除；失败按退避间隔重试。后台页面失效时缓存文字仍可使用。
