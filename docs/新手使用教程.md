# 浮读新手使用教程

适用于 macOS 0.26.18 与 Windows 0.29.2 测试版。两个平台版本独立，Windows 和 Apple 芯片当前包仍需实机验证。

## 1. 选择对应下载

Intel Mac 下载文件名含 Intel 的 ZIP；M 系列 Mac 下载 AppleSilicon 的 ZIP；Windows 10 22H2／11 的普通 x64 电脑下载 Windows-x64 的 ZIP。

请从 GitHub Releases 下载应用附件，绿色 Code 按钮下载的是源码。仓库未发布 Release 时，先使用维护者提供的测试包。

## 2. 安装与打开

macOS：先退出旧版，解压，把「浮读.app」拖到应用程序文件夹，再打开。临时签名、未公证的包可能显示开发者验证提示，请按系统安全说明处理，不要关闭系统保护。

Windows：先退出旧版，完整解压 ZIP 到新文件夹，双击 FloatingReader.exe。不要直接在 ZIP 里运行，也不要只拿出 exe。包内已带 .NET 运行时。

Windows 如果提示缺少 WebView2，请安装微软 Edge WebView2 Evergreen Runtime。如果提示缺少中文 OCR，在系统设置的语言选项中添加中文光学字符识别功能。

## 3. 打开一本书

1. 点击左上角书架按钮，按微信读书网页提示登录自己的账号。
2. 点击有权阅读的书籍，等待正文就绪，应用自动进入纯文字。
3. 首批文字出现后可以开始读，本章后续内容和下一章会后台准备。
4. 鼠标放在阅读区域滚动。下滑到末尾会请求接续；尚未完成时保留当前内容，准备好后继续。

不是所有书籍都能可靠识别。遇到错误，先检查原网页、登录和书籍访问权限。

## 4. 看懂模式按钮

正文是纯文字时，按钮显示「原网页」，点击返回原网页。

正文是原网页时，按钮显示「纯文字」，点击重新读取正文。

按钮表示切换目标，不是当前模式名称。主动返回网页后，同一页不会立即强制切回文字。

## 5. 调整样式

下方工具依次调整字号、行间距、文字颜色、字体和正文背景色。字号与行距使用滑块；字体列表来自本机。

选色窗口可以拖开，没有遮罩。色轮、色样和颜色值用于选色；Windows 明暗条是左白右黑。文字颜色和背景颜色分开记住，关闭选色窗口也保留设置。

首次默认使用系统字体、14 pt、1.4 倍行距、文字 #333333、背景 #FBF6ED。已有配色会继续使用。想恢复初始样式，在阅读菜单或窗体右键菜单选择「恢复默认阅读样式」。

新版没有透明度滑块、顶部粘贴按钮或深色模式按钮。通过独立文字色和背景色调整阅读配色。

## 6. 隐藏、拖动与缩放

顶部隐藏按钮会一起隐藏工具栏、边框和正文背景，文字保持可见。macOS 按 Command+/，Windows 按 Ctrl+/ 可以恢复；再按一次隐藏。

正文不支持框选复制。阅读区域按住左键可拖动；隐藏时整个阅读区域均可拖动。四边用于调整大小，四角可以同时改变宽度和高度。

点击窗口会先恢复浮读的应用焦点，再处理操作。点击置顶按钮或按置顶快捷键可以在置顶与非置顶之间切换。

Windows 未激活窗口的滚动还受系统「悬停时滚动非活动窗口」设置影响。

## 7. 换章与预读

正文底部左侧 ← 是上一章，右侧 → 是下一章。顶部目录按钮可以搜索并选择章节。

后台按大页面读取，窗口缩小只改变显示折行。下一章预读好后切章优先用缓存，并准备再下一章。预读失败按间隔重试，已完成缓存不会因闲置定时删除。

网络、网页绘制、OCR 和书籍权限都会影响速度，不能保证零等待。加载失败时保留当前正文，不建议连续重复点换章。

## 8. 常用快捷键

| 功能 | macOS | Windows |
| --- | --- | --- |
| 显示／隐藏工具栏与背景 | Command+/ | Ctrl+/ |
| 置顶／取消置顶 | Command+P | Ctrl+P |
| 增大／缩小字号 | Command+加号／减号 | Ctrl+加号／减号 |
| 上一章／下一章 | Command+↑／↓ | Ctrl+↑／↓ |
| 纯文字／原网页 | Command+R | Ctrl+R |
| 关闭 | Command+Q | Alt+F4 或 Ctrl+Q |

右上角键盘图标修改快捷键：点击对应功能的组合键，按下新组合，冲突时按提示更换。设置面板中的输入框仍保留系统复制和粘贴操作。

## 9. 阅读位置与反馈

应用保存本地阅读位置，退出时尝试应用到原网页。微信读书是否保存到云端由网站决定；换设备前建议返回原网页核对，不把云端同步当作保证。

如果看到错字、漏字、重复或切章错误，先切到原网页确认。同一章节的旧缓存不会自动补回先前漏掉的文字，需要重新读取。

通过 macOS 阅读菜单或 Windows 窗体右键「复制阅读诊断」，附上系统、芯片、应用版本、步骤和截图。发送前删除私人书籍标识，不发送 Cookies 或完整账号目录。
